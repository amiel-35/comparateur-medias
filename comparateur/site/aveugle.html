Le vote à l’aveugle se fait depuis votre compte

Dix titres d’un même média, sans son nom : où le placez-vous, de la gauche à la droite ? Cette question se pose désormais dans votre compte, rubrique Panel. Il faut être membre du panel.

Ouvrir la rubrique Panel

Une fois par trimestre, ce site vous remet une carte de votant. Vos avis partent avec elle, pas avec votre nom. Ce site sait à qui il a remis une carte ; il ne sait pas quels avis cette carte a donnés.

Les avis déjà donnés sur cette page sont gardés, sans nom. Ils comptent dans les résultats publiés. Si ce navigateur gardait le code de l’ancien vote, il est effacé : il ne sert plus.
